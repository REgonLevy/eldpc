## All claims

**Status vocabulary.**

- **source**: the claim is a property of the code or the build files named in the evidence
  column; reading them settles it.
- **test**: a test in this repository checks the claim; the evidence column names it. The test
  passes or fails on the machine it runs on; the recorded runs of the test suite are in
  `tools/results/matrix/tested-configurations.json`.
- **record**: a committed results file records the measurement the claim states; the evidence
  column names it.
- **tuning record**: the evidence is the measured tuning knowledge in
  [tuning/KNOWLEDGE.md](../tuning/KNOWLEDGE.md), which names the machine of every row (section
  0.2). Those machines are not the deployment classes of this package.
- **to be measured**: no record in this repository supports the claim yet. The evidence column
  names the command and the results file that will (the commands are listed in
  [RESULTS.md](RESULTS.md), "Reproducing these results"). When the record is committed, cite it
  and change the status. `docs/results/target/` holds the records of the Sapphire Rapids-W + L40S
  proxy machine, and `docs/results/` those of an RTX 6000 Ada with a Zen 2 EPYC host; what depends
  on the deployment pair itself (an RTX 6000 Ada with a Sapphire Rapids host, for example its
  absolute latency) stays "to be measured" until a record from that pair is committed.

**Revisions.** A claim or a record that names a commit (for example revision `f44723c` in claim 2)
names a revision of the development history this repository was released from. That history is
not part of this repository, which starts at its release commit. The decoder-core sources in
`src/core/` and `src/cpu/` were not changed in that history except for the neutralisation of
their comments before the release (`tools/results/comment-neutralisation/record.txt`;
`python3 tools/check_comment_only.py --check` checks their code against `src/*/TOKENS.sha256`).
